# Landmark modelling

Before adding or changing a city landmark, read [the shared modelling guide](docs/landmark-modeling/README.md), the [numbered building checklist](docs/landmark-checklist.md), and that landmark's source notes in `docs/`.

Use the checklist's permanent `SG-…` IDs and ownership rules. Work only on an assigned or exclusively claimed scope; an unmerged private checklist edit does not prevent duplicate work. Update the relevant checklist row in every landmark PR, including follow-up fixes, with the owner, status, source notes, verification evidence and actual PR link. Mark a building complete only when the checklist's acceptance criteria are met on the shared branch.

Use the existing landmark kit and city generator, preserve mapped courts and neighbouring buildings, and verify the rendered model as well as its geometry and collision tests. Document source links and estimated dimensions. The guide applies to Codex, Claude Code, Meta Muse and human contributors.
